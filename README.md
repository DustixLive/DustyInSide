# DustyInSide

Личный сайт-коллекция полезных инструментов, нейросетей, промптов, навыков и проектов.

Personal collection of useful tools, AI services, prompts, skills and projects.

## Features

- 🌐 Двуязычный интерфейс (RU / EN)
- 🌙 Тёмная и светлая темы
- 📱 Адаптивный дизайн (PC + Mobile)
- 📂 Сетка карточек с подробной информацией
- 🚀 Список личных проектов

## Tech Stack

- Pure HTML / CSS / JavaScript
- CSS Variables (themes)
- LocalStorage (сохранение темы и языка)
- GitHub Pages

## Structure

```
/

├── tools.html          # Инструменты / Нейросети
├── prompts.html        # Сборники промптов
├── skills.html         # Навыки для НН
├── css/
│   └── style.css
├── js/
│   └── main.js
├── assets/
├── .gitignore
├── LICENSE

```

## Development

Сайт работает на чистом HTML/CSS/JS.  
Для локального просмотра можно просто открыть `index.html` или использовать Live Server.
